Tối ưu tốc độ đối chiếu bài tập trên Windows

Được thiết kế tinh gọn bằng thư viện chuẩn Python & Pillow, không cồng kềnh, phản hồi bất đồng bộ mượt mà không treo giao diện.

Chụp vùng màn hình chuẩn DPI Scaling

Tích hợp SetProcessDpiAwareness giúp khoanh vùng chụp trực tiếp trên màn hình Full HD/2K bật Scaling 125%–150% mà không bao giờ bị lệch tọa độ.

Dán thông minh từ Clipboard (Ctrl+V)

Tự động nhận diện dữ liệu trong Clipboard sau khi bạn nhấn Win + Shift + S hoặc copy văn bản, chuyển thẳng ảnh tới AI hoặc điền vào khung nhập liệu.

Cắt vùng trực tiếp từ file ảnh

Mở file ảnh đề thi (PNG, JPG, WEBP), tự động xoay đúng chiều EXIF, kéo chọn riêng từng câu hỏi và nén thông minh trước khi gửi đi.

Tự động xếp hạng & dự phòng Model

Tự quét danh sách model Gemini khả dụng trên API Key, ưu tiên các bản ổn định (flash / lite) mới nhất và tự chuyển sang model dự phòng nếu gặp lỗi.

Lưu trữ API Key cục bộ an toàn

Tự động lưu khóa vào %APPDATA%\SolverProV8\config.json sau lần xác thực đầu tiên, đồng thời ẩn/che dấu key trong toàn bộ thông báo lỗi.

Chạy trực tiếp file thực thi độc lập

Phù hợp cho máy Windows 10/11 (64-bit) chưa cài đặt Python

dist\SolverProV8.exe
  1. 1 Mở thư mục dist và nhấp đúp vào file SolverProV8.exe.
  2. 2 Chờ thanh tiến trình khởi động chạy hoàn tất 100%, sau đó nhấn nút BẮT ĐẦU →.
  3. 3 Nhấn nút Dán API Key (hoặc nhập trực tiếp vào ô) → nhấn Kiểm tra & Kết nối.
  4. 4 Nếu Windows SmartScreen hiện cảnh báo do file tự đóng gói chưa ký số thương mại, chọn More info → Run anyway.

Chạy từ mã nguồn & tự đóng gói PyInstaller

Yêu cầu Python 3.10 trở lên (đã tích chọn Add Python to PATH)

solver_pro_v8.py

Bước 1: Cài đặt thư viện xử lý ảnh Pillow & chạy ứng dụng

pip install pillow
python solver_pro_v8.py

Bước 2: Tự đóng gói thành file .EXE mới (Tùy chọn)

pip install pyinstaller
pyinstaller --noconsole --onefile --name SolverProV8 solver_pro_v8.py

🔑 Cách lấy Gemini API Key miễn phí

Truy cập Google AI Studio → Đăng nhập tài khoản Google → Chọn Get API key → Create API key → Sao chép chuỗi khóa và dán vào ứng dụng.
