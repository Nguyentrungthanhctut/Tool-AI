🚀 1. Hướng dẫn tải và sử dụng SolverProV8.exe (Windows)

Khuyên dùng • Nhanh nhất
  • 1
    Tải tệp SolverProV8.exe về máy tính

    Nhấn nút Tải SolverProV8.exe ở đầu trang để tải trực tiếp tệp thực thi từ kho GitHub về thư mục Downloads.

  • 2
    Khởi chạy chương trình (Vượt qua cảnh báo Windows SmartScreen)

    Nhấp đúp vào SolverProV8.exe. Nếu Windows hiện thông báo "Windows protected your PC" do file tự đóng gói cá nhân chưa ký số thương mại, hãy bấm More info → chọn Run anyway.

  • 3
    Màn hình khởi động (Splash Screen)

    Chờ thanh tiến trình tải hệ thống chạy từ 0% → 100%, sau đó nhấn nút BẮT ĐẦU → để sang bước kết nối API.

  • 4
    Nhập Gemini API Key & Sử dụng các công cụ giải bài

    Bấm Dán API Key → nhấn Kiểm tra & Kết nối (Key tự động lưu vào %APPDATA%\SolverProV8\config.json cho các lần sau). Tại màn hình chính:

    • Chụp vùng màn hình: Kéo chuột khoanh vùng đề bài trên màn hình (hỗ trợ chuẩn tọa độ ngay cả khi bật Windows Scaling 125%–150%, nhấn Esc để hủy).

    • Dán (Text / Ảnh) hoặc Ctrl + V: Chụp nhanh bằng Win + Shift + S rồi bấm Ctrl + V trong app để tự động gửi ảnh giải ngay.

    • Cắt từ file ảnh / Chọn file ảnh giải ngay: Mở ảnh PNG, JPG, WEBP (tối đa 10 MB) để khoanh vùng từng câu hoặc giải toàn bộ ảnh.

    • Thanh trượt góc dưới (75%–100%): Điều chỉnh độ mờ cửa sổ để đặt đè lên tài liệu PDF/đề thi mà không che chữ.

💡 Lưu ý nếu tải từ GitHub bị lỗi không mở được: Hãy kiểm tra dung lượng file tải về phải đạt khoảng 16.7 MB. Nếu file tải về chỉ nặng vài trăm byte (do Git LFS), bạn hãy vào mục Releases trên GitHub Tool-AI và đính kèm file SolverProV8.exe trực tiếp vào bản phát hành (Release) để tải file nhị phân gốc.

🧩 2. Hướng dẫn cài đặt SolverProV8_Extension_Flat.zip (Trình duyệt)

Chrome • Edge • Cốc Cốc
  • 1
    Giải nén gói tiện ích

    Tải SolverProV8_Extension_Flat.zip từ GitHub, chuột phải chọn Extract All... để giải nén ra thư mục SolverProV8_Extension_Flat (đảm bảo bên trong chứa trực tiếp manifest.json, popup.html, popup.css, popup.js, content.js và chép kèm logo.jpg).

  • 2
    Mở trang quản lý tiện ích của trình duyệt

    Truy cập chrome://extensions (trên Google Chrome / Cốc Cốc) hoặc edge://extensions (trên Microsoft Edge).

  • 3
    Bật chế độ nhà phát triển & Tải tiện ích

    Bật công tắc Developer mode (Chế độ dành cho nhà phát triển) ở góc trên bên phải → nhấn Load unpacked (Tải tiện ích đã giải nén) → chọn thư mục SolverProV8_Extension_Flat vừa giải nén.

  • 4
    Ghim và thao tác trên trang web

    Nhấn biểu tượng mảnh ghép trên thanh công cụ trình duyệt → ghim Solver Pro V8 - ThanhDevHub. Bấm Chụp vùng trên web để khoanh vùng trực tiếp trên tab đang mở, sau đó mở lại popup để nhận kết quả.

📜 3. Hướng dẫn chạy từ mã nguồn solver_pro_v8.py & đóng gói với SolverProV8.spec

Dành cho lập trình viên
  • 1
    Chuẩn bị thư mục mã nguồn

    Đặt 3 tệp solver_pro_v8.py, SolverProV8.spec và logo.jpg vào cùng một thư mục trên máy tính đã cài Python 3.10+.

  • 2
    Cài đặt thư viện xử lý ảnh Pillow & chạy trực tiếp
    pip install pillow && python solver_pro_v8.py
  • 3
    Đóng gói lại thành file SolverProV8.exe mới (kèm logo.jpg)

    Dùng PyInstaller để xuất ra tệp thực thi mới nằm trong thư mục dist/SolverProV8.exe:

    pip install pyinstaller && pyinstaller --noconsole --onefile --icon=logo.jpg --add-data "logo.jpg;." --name SolverProV8 solver_pro_v8.py

    Dán chuỗi khóa vừa sao chép vào ứng dụng. Hệ thống sẽ tự động quét danh sách model gemini-* khả dụng, ưu tiên bản Flash / Lite ổn định mới nhất và tự chuyển sang model dự phòng nếu gặp lỗi.
