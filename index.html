Hướng dẫn cài đặt & sử dụng

Chọn một trong ba hình thức sử dụng phù hợp với thiết bị của bạn.

  • 1
    Nhấn nút Tải SolverProV8.exe ở đầu trang (file nằm trong thư mục dist/SolverProV8.exe, dung lượng ~16.7 MB).
  • 2
    Nhấp đúp vào SolverProV8.exe. Nếu Windows SmartScreen hiện cảnh báo, chọn More info → Run anyway.
  • 3
    Chờ thanh khởi động chạy xong 100%, nhấn BẮT ĐẦU →.
  • 4
    Lấy API Key miễn phí tại Google AI Studio, bấm Dán API Key → Kiểm tra & Kết nối (Key sẽ được tự động lưu cho các lần mở sau).
  • 1
    Nhấn Tải Extension (.ZIP) ở đầu trang và giải nén ra một thư mục (đảm bảo thấy file manifest.json bên trong).
  • 2
    Mở Chrome, Edge hoặc Cốc Cốc, truy cập địa chỉ chrome://extensions (hoặc edge://extensions).
  • 3
    Bật công tắc Developer mode (Chế độ dành cho nhà phát triển) ở góc trên bên phải.
  • 4
    Bấm Load unpacked (Tải tiện ích đã giải nén) → chọn thư mục vừa giải nén và ghim biểu tượng lên thanh công cụ.

Yêu cầu máy đã cài sẵn Python 3.10+:

pip install pillow
python solver_pro_v8.py

Nếu muốn tự đóng gói lại thành file .exe sau khi chỉnh sửa code:

pyinstaller --noconsole --onefile --name SolverProV8 solver_pro_v8.py

Cấu trúc thư mục & Lưu ý đóng gói

Sơ đồ tổ chức file chuẩn để trang web tải đúng đường dẫn dist/SolverProV8.exe.

📦 Thu_muc_Web_va_App/
 ┣ 📜 index.html               # Trang web giới thiệu & tải xuống này
 ┣ 📂 dist/
 ┃ ┗ 🚀 SolverProV8.exe        # File chạy chính thức (16.7 MB)
 ┣ 📂 build/                   # Thư mục tạm PyInstaller (không cần upload lên host)
 ┣ 📜 solver_pro_v8.py         # Mã nguồn Python gốc
 ┗ 📜 SolverProV8.spec         # File cấu hình PyInstaller

💡 Lưu ý khi đưa trang web lên Hosting / GitHub Pages

  • Đặt file index.html nằm cùng cấp với thư mục dist/ (giống hệt cấu trúc trong file Cài exe.zip của bạn) để nút Tải SolverProV8.exe hoạt động ngay mà không cần sửa đường dẫn.
  • Không cần tải thư mục build/ lên máy chủ web để tiết kiệm dung lượng lưu trữ.
  • Nút Tải Extension (.ZIP) trên trang này tự động đóng gói trực tiếp 5 file tiện ích trình duyệt ngay trên trình duyệt người dùng mà không cần lưu thêm file .zip phụ trên server.
